# Twinsanity Studio

A level editor for Crash Twinsanity and Crash Bandicoot: The Wrath of Cortex, made for Mac.

Open your own copy of the game, look through its levels, models and textures, place and move objects in 3D, then save your changes back to the game.

## Download

Get the latest version from the [Releases](https://github.com/HAB3X/Twinsanity-Studio/releases) page. Unzip it and open Twinsanity Studio. The first time, right click the app and choose Open.

You need a Mac with Apple silicon running macOS 14 or newer, and your own copy of the game.

## Build it yourself

```
swift build -c release
```
